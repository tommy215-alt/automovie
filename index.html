automovie

自分の YouTube チャンネルに、自分で作った動画を予約投稿するための道具です。
A personal tool that schedules uploads of the owner's own videos to the owner's own YouTube channel.

このアプリがすること

  • 持ち主のパソコンで作った動画ファイルを、持ち主の YouTube チャンネルに、公開日時の予約つきでアップロードします。
  • アップロード先を取り違えないよう、接続している YouTube チャンネルの名前と ID を読み取ります。

このアプリがしないこと

  • 持ち主以外の人が使うことは想定していません（一般向けのサービスではありません）。
  • 動画の削除、コメントの操作、視聴者の情報の取得はしません。
  • データを外部のサーバーに送ったり、第三者に渡したりしません。

What this app does (English)

automovie runs on the owner's own computer. It uses the YouTube Data API to upload video files created by the owner to the owner's YouTube channel with a scheduled publish time, and reads the connected channel's name and ID to make sure uploads go to the intended channel. It is not offered as a service to the general public.
