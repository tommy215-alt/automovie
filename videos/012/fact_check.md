# 012 事実確認

題材：プラスチックのひもが首に食い込んだキタオットセイの子どもが、手当てを受けて海へ帰った（米国オレゴン州、2018 年 1 月）。

| 台本で言うこと | 確かめた内容 | 出典 |
|---|---|---|
| 2018 年 1 月、アメリカ・オレゴン州 | 2018-01-22（月）朝に見つかり、01-24（水）に放された | KATU（2018-01-23）、KEX 1190（2018-01-25）、BLM の映像の説明（2018-01） |
| 海辺の駐車場で見つかった | ウィンチェスター湾（Winchester Bay）の RV（キャンピングカー）用の駐車場。海から道路を渡って入り込んだらしい（水族館の見立て） | KATU、Local12（Sinclair 系列の配信） |
| 見つけたのは | NOAA Fisheries（米国海洋大気庁の水産局）の職員 | KEX 1190、Local12 |
| キタオットセイの子ども（オス） | male northern fur seal pup | KATU |
| プラスチックのひもが首に食い込んでいた | ひもは風船か梱包材のものらしい。厚い毛と皮膚を切り、首と腹のまわりに傷 | KATU、KEX 1190 |
| 長いあいだ絡まったまま、体が大きくなって締めつけた | 水族館の Jim Burke 氏「長いあいだ絡まっていた。成長するあいだもひもがあり、締めつけて深い擦り傷を作った」 | KEX 1190、Local12 |
| 外さなければ助からなかった | 同氏の発言として報道（「ほどかなければ生き延びられなかった」） | 検索結果の要約（Local12 系列の記事）。**台本では言い切らず「このままでは命が危なかった」程度にとどめる** |
| 水族館がひもを外し、手当て | オレゴン・コースト水族館がすぐにひもを外し、傷の手当て、抗生物質と水分を 3 日 | KATU、KEX 1190 |
| 元気だった | 「元気で（feisty）、体の状態もかなりよかった」 | Local12 |
| ヤキーナ岬の入り江で放した | Yaquina Head Outstanding Natural Area の Quarry Cove。水族館の職員と、オレゴン海獣座礁ネットワークの Jim Rice 氏が運んだ | KEX 1190、BLM の説明 |
| 運搬用の箱からおそるおそる顔を出し、海へ | 「おそるおそるケージから顔を出し、水へ向かった」「波の穏やかな所でしばらく毛づくろいをして泳いだ」「波の切れ目を越えて外海へ出たとき、職員は歓声を上げた」 | KEX 1190（水族館の発表の引用） |
| そのあと | BLM のレンジャーが数日見回り、その場所を無事に離れたと報告 | BLM の映像の説明（Commons のファイルの説明に転載） |
| 生まれは | ベーリング海のプリビロフ諸島で夏の初めに生まれたとみられる（推定） | Local12。**台本では「遠い北の海で生まれたとみられる」程度に** |
