# 投稿前の検査（1 つでも × なら投稿しない）

## 権利
- [ ] 使った映像・画像・音楽のすべてが `videos/NNN/assets.md` に、出典の URL とライセンスつきで載っている
- [ ] 他人の投稿動画、スポーツ中継、テレビ・映画・アニメの映像を使っていない
- [ ] 表示が必要な素材（CC BY など）のクレジットが説明欄にある

## 中身
- [ ] 事実・数字に出典があり、`fact_check.md` に残っている
- [ ] 独自の解説・比較・結論が入っている（映像と音楽だけになっていない）
- [ ] 直近 10 本と題材・タイトルの型がかぶっていない
- [ ] 実在の人物・団体をおとしめる内容、誤解を招く見出しがない

## 映像と音
- [ ] 1080×1920・30 fps・60 秒以内
- [ ] 最初の 1 秒で何の動画か分かる
- [ ] 字幕が読める（はみ出し・重なり・誤字がない。YouTube のボタンの位置にかぶらない）
- [ ] ナレーションの読み間違いがない。音量がそろっている（−14 LUFS 前後）
- [ ] 音声の検査 `python -X utf8 tools/check_audio.py videos/NNN` が合格（完成版の音を音声認識で起こし、台本の読みと行ごとに比べる。一致率 0.80 以上、早口・長い間・音割れなし）。不合格の行は台本の `say` を直して声から作り直す（3 回まで）。結果は `work/qa/audio_check.json`
- [ ] 最初から最後まで通して見て、止まり・黒画面・音切れがない

## 投稿の情報
- [ ] タイトル・説明文・ハッシュタグがある（`videos/NNN/youtube_metadata.md`）
- [ ] 「改変または合成されたコンテンツ」の申告を正しく選んでいる
