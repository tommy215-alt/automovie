# チャンネルの名前・アイコン・説明文（案）

チャンネルの名前とアイコンは、YouTube の決まりで API からは変えられない。ユーザーが YouTube の画面で設定する。

## 名前の案

| 案 | ねらい |
|---|---|
| **世界の60秒**（おすすめ） | 「海外の出来事を 1 分で」という中身がそのまま伝わる。感動・救助・すごい人・動物・ハプニングのどれにも合うので、題材を変えても名前がずれない。アイコンはこの名前で作ってある |
| 地球のいい瞬間 | 感動・いい話に寄せるならこちら。衝撃・笑える系には少し合いにくい |
| せかい実話便 | 「実際にあった話」を前に出す。作り話のチャンネルとの違いが出る |

似た名前の強いチャンネル（「1分感動シアター」「世界の感動ストーリー」「ほっこりショート」）とは、かぶらないようにした。同じ名前のチャンネルがないかは、YouTube で検索して確かめてから決める（未確認）。

## アイコン

`channel/icon.png`（800×800）。紺の地に黄色の輪（ストップウォッチ）と「世界の 60 秒」。丸く切り抜かれても文字が欠けない。自作で、他人の素材は使っていない。小さく表示したときの見え方は `channel/icon_preview.png`。

```
救助、再会、すごい人、動物たち。毎日18時に更新。

映像は、権利者が再利用を認めているもの（パブリックドメインやクリエイティブ・コモンズ）だけを使い、出典は各動画の説明欄に記しています。
ナレーション：VOICEVOX
```
