# YouTube へ自動で上げるための設定（かんたん版）

最初の 1 回だけ。無料、15 分ほど。

## やること

1. ブラウザ（Chrome など）で、**automovie 用の新しいチャンネルの Google アカウント**にログインしておく。
   RE:VERSE のアカウントでログインしている場合は、先に切り替える。
2. エクスプローラーで `C:\Users\Duncan_Tommy21\automovie` を開き、
   **`YouTubeの設定を始める.bat` をダブルクリック**する。
3. 黒い画面に「手順 1／6」と出て、必要なページが自動で開く。
   黒い画面に書いてあるとおりにボタンを押し、できたら黒い画面で **Enter** を押す。これを 6 回くり返す。
4. 最後に「つながったチャンネル：○○」と出たら終わり。**チャンネルの名前が合っているか見る。**
5. Claude に「設定した」と伝える。

## 6 つの手順でやること（黒い画面にも同じことが出る）

| 手順 | 開く画面 | 押すもの |
|---|---|---|
| 1 | YouTube | 「チャンネルを作成」（もうあれば何もしない） |
| 2 | Google Cloud：新しいプロジェクト | 名前に `automovie` →「作成」 |
| 3 | YouTube Data API v3 | 「有効にする」 |
| 4 | Google Auth Platform | 「開始」→ アプリ名 `automovie`、自分のメール、「外部」→「作成」。そのあと左の「対象」→「アプリを公開」 |
| 5 | クライアントの作成 | 「デスクトップ アプリ」→「作成」→「JSON をダウンロード」 |
| 6 | Google の許可の画面 | 新しいアカウントを選ぶ →「詳細」→「automovie に移動」→ チェック 2 つ →「続行」 |

ダウンロードした鍵のファイルは、道具が自動で正しい場所へ移す（名前の変更や移動はいらない）。

## 困ったとき

- **画面の見た目が説明と違う／ボタンが見つからない** → その画面のスクリーンショットを Claude に送る。どこを押すか答える。
- **途中でやめてしまった** → もう一度 `YouTubeの設定を始める.bat` をダブルクリックする。済んだ手順は Enter で飛ばしてよい。
- **「このアプリは Google で確認されていません」と出る** → 自分で作ったアプリなので問題ない。「詳細」→「automovie（安全ではないページ）に移動」。
- **つながったチャンネルの名前が違う** → 別のアカウントで許可してしまっている。ブラウザのアカウントを切り替えて、bat をもう一度実行する。

## 守ってほしいこと

- **パスワードや、ダウンロードした鍵のファイルの中身を、チャットに貼らない。**
- 設定は必ず新しいチャンネルのアカウントで。RE:VERSE のアカウントを選んだ場合、道具は許可を捨てて止まる。

## 設定のあとに起きること

- 毎日、検査を通った動画が 18:00（日本時間）の予約で上がる。上げ先は、手順 6 でつながったチャンネルだけ。
- **最初の 1 本だけ、YouTube Studio で「予約済み」と表示されているか見てほしい。** 新しく作った API からの動画が、予約どおり公開されるかは、やってみないと分からない（以前の YouTube では非公開のままになった）。

## やめたいとき

https://myaccount.google.com/permissions で `automovie` を削除する。

## 注意（Claude 側で確かめられていないこと）

- 手順 2〜5 で開くページの場所は、Google が画面を変えるとずれることがある。ずれていたらスクリーンショットを送ってほしい。
