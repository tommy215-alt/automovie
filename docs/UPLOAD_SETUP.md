# YouTube へ自動で上げるための設定（最初の 1 回だけ、ユーザー本人が行う）

無料。課金の登録はいらない。かかる時間は 15〜20 分。
**パスワードや鍵のファイルの中身を、チャットや Claude に貼らないこと。** ファイルを決まった場所に置くだけでよい。

作業は必ず **automovie 用の新しいチャンネルの Google アカウント** で行う（RE:VERSE のアカウントでは行わない）。

## 1. YouTube のチャンネルがあるか確かめる

https://www.youtube.com を新しいアカウントで開き、右上のアイコン →「チャンネルを作成」まで済ませておく（アカウントを作っただけでは、チャンネルはまだない）。

## 2. Google Cloud でプロジェクトを作る

1. https://console.cloud.google.com/ を**同じ新しいアカウント**で開く（規約の同意を求められたら、内容を読んでご自身で同意する）。
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前は `automovie` → 作成。

## 3. YouTube Data API を有効にする

「API とサービス」→「ライブラリ」→ `YouTube Data API v3` を検索 →「有効にする」。

## 4. 同意画面を作る

「API とサービス」→「OAuth 同意画面」（「Google Auth Platform」と出ることもある）。
- アプリ名：`automovie`、サポートのメール：自分のアドレス
- 対象（User Type）：**外部**
- 連絡先のメール：自分のアドレス → 保存
- 「対象」または「テストユーザー」に、**新しいチャンネルのアカウントのアドレス**を追加する
- **公開の状態を「本番環境」にする**（「アプリを公開」）。「テスト」のままだと、許可が 7 日ごとに切れて自動化が止まる。確認の申請は出さなくてよい（自分だけで使うため）。

## 5. 鍵のファイルを作って置く

1. 「API とサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」。
2. アプリケーションの種類：**デスクトップ アプリ**、名前は `automovie-pc` → 作成。
3. 「JSON をダウンロード」。
4. ダウンロードしたファイルの名前を `client_secret.json` に変えて、次の場所に置く：

```
C:\Users\Duncan_Tommy21\automovie\publish\client_secret.json
```

このファイルは git に入らない設定にしてある（`.gitignore`）。

## 6. 許可する（ブラウザが開く）

ターミナルで：

```
cd C:\Users\Duncan_Tommy21\automovie
python tools/youtube_upload.py auth
```

- ブラウザが開く。**新しいチャンネルのアカウント**を選ぶ。
- 「このアプリは Google で確認されていません」と出たら、「詳細」→「automovie（安全ではないページ）に移動」。自分で作ったアプリなので問題ない。
- 「YouTube 動画の管理」「YouTube アカウントの表示」にチェックを入れて「続行」。
- ターミナルに「つながったチャンネル：○○」と出れば完了。**チャンネル名が正しいか必ず見る。**

## 7. 確かめる

```
python tools/youtube_upload.py check
```

チャンネルの名前と ID が出れば OK。ここまで済んだら、制作のセッションに「設定した」と伝える。

## この道具が守ること

- 上げるのは、手順 6 で記録したチャンネル（`publish/channel.json`）だけ。上げる直前に毎回確かめ、違えば止まる。
- 名前に RE:VERSE を含むチャンネルには上げない。手順 6 で RE:VERSE のアカウントを選んでしまった場合は、許可を捨てて止まる。
- 検査（`qa.md`）に未チェックの項目がある回、すでに上げた回は上げない。
- 動画は「非公開＋公開の予約」で上げる。予約の時刻になると YouTube が自動で公開する。

## 分かっていないこと（最初の 1 本で確かめる）

- 新しく作った API のプロジェクトから上げた動画が、予約どおり公開されるか。以前の YouTube の決まりでは、審査を受けていないプロジェクトから上げた動画は非公開に固定された。いまの公式の資料では固定されないと読めるが、**最初の 1 本を上げたあと、YouTube Studio で予約の表示を見て確かめる**。固定される場合は、Studio で手で公開にするか、YouTube に API の審査を申し込む。
- 1 日に上げられる本数の上限（公式の資料では 1 日 100 回まで。1 日 1 本なら問題ない）。
- 新しいチャンネルは、電話番号の確認をしないと 15 分を超える動画などに制限がある（ショートには影響しない）。

## やめたいとき

https://myaccount.google.com/permissions で `automovie` のアクセス権を削除し、`publish/token.json` を消す。
