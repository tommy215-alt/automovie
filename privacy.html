プライバシー ポリシー

最終更新：2026 年 11 月 11 日

automovie（以下「本アプリ」）は、持ち主が自分のパソコンで動かし、自分の YouTube チャンネルに自分の動画を予約投稿するための道具です。

1. 取得する情報

本アプリは、持ち主が Google の画面で許可したときに限り、YouTube API サービスを通じて次の情報にアクセスします。

  • 接続した YouTube チャンネルの名前と ID（アップロード先の確認のため）
  • アップロードを行うための認証情報（Google が発行するトークン）

視聴者の情報、連絡先、メールの内容、そのほかの Google アカウントのデータは取得しません。

2. 利用の目的

  • 持ち主が作った動画を、持ち主の YouTube チャンネルへアップロードし、公開日時を予約するため
  • アップロード先のチャンネルが正しいことを確かめるため

3. 保存と共有

  • 認証情報とチャンネルの名前・ID は、持ち主のパソコンの中にだけ保存します。
  • 本アプリは独自のサーバーを持たず、これらの情報を第三者に送信・共有・販売しません。
  • 通信の相手は Google（YouTube API サービス）だけです。

4. 削除とアクセス権の取り消し

  • パソコンに保存した認証情報のファイルを削除すれば、本アプリは YouTube にアクセスできなくなります。
  • Google アカウントの セキュリティ設定（アクセス権の管理） から、いつでも本アプリのアクセス権を取り消せます。

5. YouTube API サービスについて

本アプリは YouTube API サービスを使っています。本アプリを使う人は、YouTube 利用規約 に同意したものとみなされます。Google によるデータの扱いは、Google プライバシー ポリシー をご覧ください。

6. 変更

本ポリシーを変更したときは、このページで知らせます。

Privacy Policy (English summary)

automovie is a personal tool run on its owner's computer. With the owner's consent on Google's authorization screen, it uses YouTube API Services to (1) upload the owner's videos to the owner's YouTube channel with a scheduled publish time and (2) read the connected channel's name and ID to confirm the upload destination. Authorization tokens and the channel name/ID are stored only on the owner's computer. The app has no server of its own and does not transmit, share or sell any data to third parties; it communicates only with Google. Access can be revoked at any time at Google security settings, and locally stored credentials can be deleted. By using this app, users agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy.
